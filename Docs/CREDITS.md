# X-RIM credits

Where every sound (and, later, every piece of art) that was not made for X-RIM comes from, with its licence. Fill in one row per file **when you download it**, while its page is still open. This file becomes the game's credits screen, and it is your proof that each file may be used. How to choose safe licences: `Docs/SOUND_GUIDE.md`, part 3.

What to write in each column:

- **File:** the file's name in `Assets/XRim/Audio/Incoming/`, for example `hit_light_01.wav`.
- **What it is:** a few words, for example "metal impact".
- **Source:** the website or bundle, for example Freesound, Kenney, Sonniss GDC 2025, Pixabay, or "recorded by me".
- **Author:** the person or studio named on the page ("–" when none is given).
- **Licence:** exactly as the page says: CC0, CC BY 4.0, Pixabay Content License, Sonniss GDC licence…
- **Link:** the web address of the sound's page.
- **Changes:** what you did to it, for example "trimmed, normalized".

A **CC BY** sound *must* be credited: write the author and the link exactly as the page asks.
